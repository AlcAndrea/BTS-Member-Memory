# ⟭⟬ BTS Photocard Flipper & Matching Game

An interactive, responsive memory-matching game built with HTML5, CSS3, and Vanilla JavaScript. Test your memory by flipping photocards to match all 7 BTS members plus a bonus group card!

---

## 🌟 Features

* **3D Card Flip Effect:** Smooth 3D rotation animations using CSS perspective and transforms.
* **Randomized Gameplay:** Uses the Fisher-Yates shuffle algorithm so cards are randomized every game.
* **Score & Move Tracking:** Keeps track of total moves made and matched pairs.
* **Responsive Layout:** CSS Grid layout optimized for desktop and mobile screens.
* **Custom Assets:** Displays custom member photos, roles, and a BTS logo favicon.
